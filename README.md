# КП-Мастер

Локальная программа для подготовки коммерческих предложений на русском языке. Python 3.12+, без внешних зависимостей и платных API.

## Быстрый запуск в Windows

Установите Python 3.12 или новее (при установке включите добавление Python в PATH). Распакуйте архив и дважды нажмите **Start-Windows.bat**. Откроется браузер с приложением. Окно консоли оставьте открытым, для остановки нажмите Ctrl+C.

Альтернативный запуск из папки программы:

```sh
python app.py --open
```

Приложение доступно на локальном порту 8000. Для другого порта задайте переменную PORT. По умолчанию приложение слушает только 127.0.0.1.

## Обновление с первой версии

1. Остановите приложение.
2. Сохраните копию `kp.sqlite3`.
3. Замените `app.py`, `calculations.py`, папку `templates` и остальные файлы программы файлами нового архива. **Не удаляйте и не заменяйте свою базу `kp.sqlite3`.**
4. Запустите программу. Новые поля базы добавятся автоматически; старые КП и организации сохранятся.
5. Обновите страницу браузера сочетанием Ctrl+F5.

## Создать обычное КП

Выберите организацию и заполните товар, количество, закупку. Наценка берётся из настроек организации или последнего введённого значения в браузере. Добавьте следующую строку кнопкой «Добавить товар».

Под товаром кнопка «Дополнительно» открывает единицу измерения, НДС закупки, доставку и способ расчёта: наценка, целевая маржинальность либо заданная цена продажи. Доставка — сумма **на всю строку**, а не на единицу. Если доставка уже включена в закупку, оставьте 0.

Покупатель и контакты менеджера необязательны. Условия подставляются из организации и могут быть изменены для текущего КП. Несохранённый расчёт восстанавливается из локального хранилища браузера на том же устройстве. Это не замена сохранению в базе.

Нажмите «Сохранить КП» либо «Сохранить и открыть PDF». В открывшемся документе выберите «Печать / сохранить PDF», затем принтер «Сохранить как PDF». Если браузер блокирует новую вкладку, откройте документ в истории по ссылке PDF.

## История

Поиск по номеру, покупателю, организации, дате (ГГГГ-ММ-ДД); фильтр статуса. «Открыть» редактирует тот же документ и номер. «Копия» создаёт новое предложение после сохранения, с новым номером и текущими настройками организации. Статусы меняются в списке: черновик, сформировано, отправлено, согласовано, отказ, архив. Статус задаётся вручную и не означает фактическую отправку клиенту.

При редактировании существующего КП сохраняются его прежние реквизиты и налоговые правила. Выбор другой организации применяет её актуальные настройки. Закупочные цены, наценка и прибыль в печатную форму не попадают.

## Организации

В разделе «Организации» добавляйте организации или нажмите «Настроить». Укажите название, реквизиты (ИНН/КПП, адрес, банковские данные и контакты), ставку НДС, право на вычет, стандартную наценку и условия КП. Демоорганизация содержит вымышленные данные.

Печатная форма использует название и реквизиты. Загрузка логотипов и произвольных фирменных бланков пока не реализована.

## Калькулятор

Вне создания КП введите закупку, НДС поставщика, доставку и общую цену продажи. Получите сравнение всех организаций при одинаковой цене продажи. Таблица показывает входной НДС, вычет, себестоимость, исходящий НДС, сальдо НДС, прибыль и маржинальность. Лучшая прибыль выделяется звездой.

## Правила расчёта

Все введённые цены включают НДС. Входной НДС строки = закупка × количество × ставка / (100 + ставка), округлённый до копеек. Если вычет разрешён, он исключается из себестоимости. Доставка прибавляется один раз на строку; вычет её НДС не рассчитывается.

- Наценка: цена без НДС = себестоимость единицы × (1 + наценка / 100).
- Целевая маржинальность: цена без НДС = себестоимость единицы / (1 − маржинальность / 100).
- К полученной цене добавляется исходящий НДС. В режиме заданной цены используется введённая цена с НДС.
- Цена единицы и сумма строки округляются до копеек ROUND_HALF_UP, расчёты выполняются Decimal.
- Прибыль = сумма продажи − исходящий НДС − себестоимость строки.
- Маржинальность = прибыль / выручка без НДС. Рентабельность = прибыль / себестоимость.
- Сальдо НДС = исходящий НДС − разрешённый вычет. Отрицательное сальдо не означает автоматическое возмещение.

Налог на прибыль и УСН не рассчитываются. Право на вычет задаётся вручную, налоговый режим автоматически не проверяется. Настройки следует подтвердить с бухгалтером.

## Данные и резервные копии

SQLite: `organizations` — настройки организаций; `quotes` — номер, дата, покупатель, статус, сумма и JSON-снимок организации, товаров и расчётов. Новые поля добавляются при запуске. Сохранённые документы не зависят от дальнейших изменений настроек.

В разделе «Организации» нажмите «Скачать резервную копию базы». Копия создаётся штатным SQLite Backup API и содержит все сохранённые КП и организации. Для восстановления остановите приложение, сохраните текущую базу отдельно, переименуйте копию в `kp.sqlite3` и поместите в папку программы. Можно также копировать исходную базу при остановленном приложении.

База содержит коммерческую информацию: храните её защищённо, не добавляйте в Git. Приложение предназначено для одного локального пользователя; авторизация, разграничение ролей и сетевое размещение не реализованы.

## Проверки

```sh
python -m unittest -v
```

Тесты проверяют расчёты, Windows-кодировку, миграцию старой базы, сохранение/редактирование/копирование КП, налоговый снимок, статусы, печатную форму и восстановимость резервной копии. Интеграционным тестам нужен доступ к локальным сокетам.

## Дальнейшее развитие

Фирменные бланки и логотипы, серверная генерация PDF, закупки поставщиков с распределением общей доставки, импорт Excel, пользователи и роли. Текущее приложение покрывает часть исходного ТЗ, не весь проект.
