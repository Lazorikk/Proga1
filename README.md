# КП-Мастер — закупки → цены → готовое предложение

Программа для менеджера по продажам строительных материалов. Один экран для КП, отдельный калькулятор выгодности. Несколько ваших фирм с разными бланками и НДС. Без платных API и обязательной интеграции с 1С.

## Запуск в Windows

1. Установите **Python 3.12 или новее** с python.org. При установке включите «Add Python to PATH».
2. Полностью распакуйте архив в отдельную папку, например `C:\KP-Master`. Не запускайте внутри ZIP.
3. Дважды нажмите **Start-Windows.bat**. Первый запуск создаст `.venv` и установит бесплатные библиотеки PDF — в этот момент нужен Интернет.
4. Откроется браузер с программой. Окно консоли оставьте открытым. Завершение — Ctrl+C в консоли.

Потом Интернет для работы не нужен. PDF формируется локально, коммерческие данные не отправляются внешним сервисам.

Linux/macOS или запуск из терминала в папке программы:

```sh
python start.py
```

Ручная установка и запуск:

```sh
python -m venv .venv
# Windows:
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python app.py --open
# Linux/macOS:
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python app.py --open
```

Адрес при запуске: `http://127.0.0.1:8000`. Только локальный интерфейс. Если порт занят, закройте старое окно программы или задайте PORT. На Windows: `set PORT=8001`, затем `python start.py`.

## Обновление с предыдущей версии

1. Остановите программу, сделайте копию `kp.sqlite3` в другую папку.
2. Замените **все файлы программы**, включая `assets`, `templates`, `requirements.txt`, `start.py`, `quote_engine.py`, `documents.py`. **Свою базу `kp.sqlite3` не заменяйте и не удаляйте.**
3. Запустите `Start-Windows.bat`: новые библиотеки установятся автоматически.
4. Обновите браузер Ctrl+F5.

Старые КП и организации сохраняются; схема базы обновляется автоматически. Перед добавлением новых настроек к старой базе создаётся дополнительная копия `kp.before-v3.sqlite3` (если её ещё нет). Это страховка обновления, а не регулярное резервное копирование.

## Настроить один раз: ваши фирмы

Раздел **«Фирмы и бланки» → «Настроить фирму и бланк»**:

- Название, реквизиты, адрес, банк, контакты.
- Ставка НДС продажи — любая от 0 до 100%, 0 означает «Без НДС».
- Налоговый режим — пояснение для сотрудника, не автоматический выбор налоговых правил.
- Право на вычет входного НДС — отдельный флажок. Наличие НДС продажи само по себе не даёт права на вычет.
- Флажок подтверждения бухгалтером. До подтверждения программа показывает предупреждение об условности результата.
- Стандартная наценка, срок поставки, срок действия, оплата и контакты менеджера.

Изменять организации можно без изменения кода. Сохранённые КП хранят снимок реквизитов, бланка и налоговых правил. Последующее изменение фирмы их не меняет.

### Загрузить свой бланк

Загрузите **одностраничный PDF без пароля, до 5 МБ**, желательно А4. Это должен быть пустой фирменный бланк: шапка, реквизиты и подвал, без старой товарной таблицы. Если исходник в Word, удалите старые товары и экспортируйте пустой бланк в PDF.

Установите отступ сверху (например 65 мм) и снизу (например 20 мм), чтобы таблица КП не перекрывала оформление. Сохраните фирму и проверьте предпросмотр. Фоновый бланк повторяется на каждой странице. При использовании бланка реквизиты должны быть уже на нём — программа не дублирует их поверх шапки.

Если PDF-бланка пока нет, загрузите логотип PNG/JPEG (до 5 МБ, 16 Мп) и выберите цвет оформления. Программа создаст собственный бланк с логотипом и реквизитами. Без логотипа тоже можно работать. Кириллица в PDF обеспечивается встроенными шрифтами DejaVu; лицензия в `assets/FONT-LICENSE.txt`.

## Создать простое КП на 1–3 товара

1. Выберите свою фирму. Покупатель необязателен.
2. Введите **товар, количество и закупочную цену**. Укажите общий НДС закупки и наценку, если отличаются от предложенных.
3. Нажмите **«Скачать PDF»** — предложение сохранится в истории, файл сразу скачается.

Поставщик, счёт, дата закупки и контакт клиента не обязательны. Доставка по умолчанию уже включена в закупку. В «Условия, сроки и контакты» подставлены значения фирмы. Последняя введённая наценка запоминается в браузере и применяется к новым закупкам; индивидуальная наценка задаётся в параметрах товара.

Предпросмотр открывает тот же PDF, который скачивается. В документ попадают название товара, единица, количество, продажная цена, сумма, срок поставки, НДС, условия, срок действия, менеджер. **Закупка, наценка, поставщики, себестоимость и прибыль не попадают в клиентский документ.**

## Жизненные ситуации

### Товары у нескольких поставщиков

Нажмите **«Другая закупка / поставщик»**. У каждого блока свои НДС, наценка и доставка. Название поставщика можно оставить пустым. Если один поставщик везёт часть товаров отдельно, создайте для них отдельный блок.

### Поставщик А: доставка уже в ценах

Выберите «Уже в закупочной цене». Дополнительная доставка не начисляется, даже если в скрытых параметрах осталась старая сумма.

### Поставщик Б: общая доставка на семь товаров

Выберите «Отдельно на эту закупку», введите всю доставку. По умолчанию она распределяется пропорционально стоимости товаров с НДС. Другие способы: по количеству, поровну на строки, по весу, по объёму. Вес и объём задаются **на единицу товара**, затем умножаются на количество.

При распределении по количеству используйте сопоставимые единицы. Штуки и тонны обычно требуют распределения по стоимости или весу.

### Поставщик В: один товар из счёта на десять позиций

Выберите **«Часть полного счёта»**. Введите только выбранный товар, доставку всего счёта и **полную сумму товарного счёта с НДС, без отдельно выставленной доставки**.

Пример: выбранные товары стоят 10 000 ₽, весь счёт — 100 000 ₽, доставка — 5 000 ₽. К выбранным товарам относится 500 ₽, 4 500 ₽ остаются на остальных. Остальные девять товаров вводить не нужно.

Для других методов укажите полную базу всего счёта: все единицы, все строки, общий вес либо объём. Полная база не может быть меньше выбранной части — программа проверяет это.

### Необычный груз: распределить доставку вручную

Выберите «Распределю вручную», введите общую доставку и долю каждой строки в «Параметрах» товара. Сумма долей должна совпадать с общей доставкой. Доля задаётся на строку целиком, не на единицу.

### НДС указан сверху или у перевозчика другой НДС

В настройках закупки раскройте «Цены закупки» или «НДС доставки и цены закупки». Можно указать цены «НДС сверху», отдельную ставку перевозчика и включён ли НДС в его сумму. Продажные цены и клиентский PDF всегда показывают цену с НДС вашей фирмы.

### У одного товара другая ставка, наценка или срок

«Параметры» под строкой. Пустые НДС и наценка означают «как в закупке». Можно выбрать свою наценку, целевую маржу или вручную задать продажную цену с НДС. Нажатие на рассчитанную продажную цену сразу включает ручной режим. Здесь же — единицы, индивидуальный срок и перемещение товара в другую закупку.

### Клиент просит скидку

В правой панели задайте процент скидки на всё КП. Она применяется к рассчитанным и ручным продажным ценам. Прибыль пересчитается; убыточные строки отмечаются предупреждением. В PDF попадут уже итоговые цены после скидки.

### Нужно быстро перенести строки из Excel

В закупке нажмите **«Вставить из Excel»**. Скопируйте без заголовка столбцы:

```
Наименование    Количество    Закупочная цена    Единица (необязательно)
```

Между столбцами — табуляция (при копировании из Excel она сохраняется) либо `;`. Поддерживаются десятичная запятая и пробелы в числах. Программа проверит строки до добавления. Это вставка таблицы, не распознавание файлов `.xlsx` или сканов.

### Уже считали похожее предложение

В истории нажмите «Копия». Новое КП получит новый номер после сохранения, текущие налоговые настройки и бланк выбранной фирмы. Закупочные цены копируются прежние — проверьте актуальность.

Для повторного использования только одной закупки нажмите «Взять закупку из прошлого КП». Исходное КП не изменяется. Общая доставка скопированной закупки фиксируется относительно полного исходного счёта, поэтому удаление лишних товаров не переложит на оставшиеся всю доставку.

### Закрыли браузер до сохранения

Несохранённый расчёт восстанавливается в том же браузере и профиле. Авточерновик — один, это не замена истории и резервной копии. Очистка данных браузера удаляет его. Сохранённые КП находятся в SQLite.

## Калькулятор закупки и НДС

Введите закупку, доставку, ставку перевозчика и цену продажи. В каждом сценарии выберите вашу фирму и НДС поставщика. Можно добавить комбинации или нажать «Сравнить мои фирмы: закупка без НДС / 7% / 22%».

Два вида задачи:

- **Одинаковая цена продажи:** сравнить прибыль при разных закупочных ставках и фирмах.
- **Целевая маржинальность / наценка:** найти необходимую цену продажи для каждой комбинации.

Показываются закупка с НДС, доставка, входной НДС, вычет, себестоимость, исходящий НДС, сальдо НДС, прибыль и маржинальность. При одной цене выделяется лучшая прибыль; при заданной цели — меньшая требуемая цена. Налог на прибыль и УСН не включены в сравнение.

Пример: покупка за 107 000 ₽ с НДС 7%, продажа за 122 000 ₽ с НДС 22%, полный вычет разрешён, доставки нет. Входной НДС 7 000 ₽, исходящий 22 000 ₽, сальдо 15 000 ₽, себестоимость 100 000 ₽, выручка без НДС 100 000 ₽, прибыль **0 ₽**.

**Вычет НДС и фактический возврат из бюджета — разные вещи.** Отрицательное сальдо само по себе не означает, что эти деньги вернутся. Программа оценивает операцию по введённым правилам; подтвердите право на вычет, налоговые условия и документы с бухгалтером. Флажок вычета предполагает, что весь заявленный входной НДС данной операции допустим к вычету; частичный вычет и особые налоговые случаи автоматически не моделируются.

## История и данные

Поиск по номеру, покупателю, фирме и дате ГГГГ-ММ-ДД; фильтры по статусу и периоду. «Открыть» редактирует тот же номер и сохраняет прежние реквизиты и налоговые правила, пока не выбрана другая фирма. Повторное сохранение увеличивает ревизию. Конфликт устаревшей вкладки не перезаписывает более свежую версию.

Статусы устанавливаются вручную: черновик, сформировано, отправлено, согласовано, отказ, архив. Изменение статуса не отправляет документ клиенту.

SQLite `kp.sqlite3` содержит организации, их профиль и бланки; КП содержат снимки фирмы, закупочных блоков, товаров, скидки, сроков и расчётов. Ограничения: до 100 товаров и 30 закупок на КП, до 20 сценариев калькулятора.

## Резервная копия

В разделе фирм нажмите «Скачать базу данных». Копия создаётся SQLite Backup API и содержит все **сохранённые** КП, бланки и организации. Для восстановления остановите программу, сохраните текущую базу отдельно и замените её скачанным файлом с именем `kp.sqlite3`. Установленная программа и библиотеки в копию не входят.

База содержит коммерческие данные, не добавляйте её в Git. Текущая версия рассчитана на одного локального сотрудника. Авторизация, разделение ролей, общая сетевая база и синхронизация нескольких компьютеров пока не реализованы.

## Математика и округление

Расчёты — Decimal. НДС внутри суммы: `сумма × ставка / (100 + ставка)`. НДС сверху: `цена × (1 + ставка / 100)`. Себестоимость = закупка с НДС + доставка с НДС − допустимый вычет. Прибыль = продажа − исходящий НДС − себестоимость.

Наценка применяется к себестоимости без возмещаемого НДС. Маржа — доля прибыли в выручке без исходящего НДС. Наценка 20% на 100 ₽ даёт 120 ₽ без НДС, маржа 20% — 125 ₽ без НДС.

Доставка полного счёта и её НДС распределяются отдельно методом наибольших остатков до копейки; выбранная часть получает только свою долю. Для «НДС сверху» сначала считается полная сумма доставки с НДС. Для ручного распределения введённые доли должны совпадать с введённой общей суммой. Входной НДС товаров округляется по строкам. Продажная цена единицы, сумма строки и исходящий НДС строки округляются ROUND_HALF_UP; итоги складываются из строк. Цена безубыточности округляется вверх до копейки. При нулевой выручке процент маржи условно отображается как 0.

Фактические счета поставщиков могут иметь иной порядок округления или условия вычета. Программа не заменяет бухгалтерский учёт.

## Проверка разработчиком

```sh
python -m pip install -r requirements.txt
python -m unittest -v
```

Тесты покрывают миграцию старой базы, копию перед миграцией, расчёты НДС/маржи/скидки, трёх поставщиков, частичный счёт, копеечные остатки, НДС перевозчика, ревизии, сохранение и копирование, резервную копию, настоящий PDF, кириллицу, отсутствие внутренних данных, многостраничный бланк. HTTP-тесты используют временные базы и локальные сокеты.

## Что пока не входит

Импорт готовых файлов Excel, распознавание счетов, загрузка Word-шаблонов, электронная отправка КП, подпись, учёт фактических оплат и закупок, серверное размещение с ролями. Одну закупку можно копировать между КП, но это не складской учёт и не контроль остатков.
