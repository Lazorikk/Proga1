# КП-Мастер — первая рабочая версия

Локальное однопользовательское веб-приложение. Требуется Python 3.12+, внешних зависимостей нет.

## Запуск

```sh
cd /workspace/Proga1
python app.py
```

Откройте в браузере адрес, выведенный программой (порт 8000). Приложение слушает только локальный интерфейс. Для нескольких сотрудников сначала необходимы авторизация, права доступа и безопасное развёртывание.

## Работа

1. В разделе «Организации» добавьте название, реквизиты, ставку НДС и право на вычет. Демоорганизация содержит вымышленные данные.
2. Выберите организацию, введите товар, количество и закупку. Наценка запоминается браузером. При необходимости укажите НДС закупки.
3. Нажмите «Сохранить и открыть КП». В документе нажмите «Печать / сохранить PDF» и выберите сохранение в PDF средствами браузера.
4. Сохранённые документы доступны в истории. Закупка, наценка и прибыль в печатную форму не включаются.

PDF пока формируется через браузер, не сервером. Фирменная форма использует название и реквизиты; загрузка логотипов и бланков пока не реализована.

## Модель и расчёты

SQLite: organizations хранит организации; quotes хранит дату, покупателя, сумму и JSON-снимок реквизитов, товаров и результатов. Изменение настроек не меняет сохранённое КП. Номер — уникальный ID записи.

Введённые цены включают НДС. Себестоимость единицы = закупка / (1 + входной НДС / 100), если разрешён вычет, иначе полная закупка. Продажная цена = себестоимость × (1 + наценка / 100) × (1 + исходящий НДС / 100). Цена и сумма строки округляются до копеек ROUND_HALF_UP. Прибыль = выручка без исходящего НДС − себестоимость. Расчёт использует Decimal.

Доставка пока включена в закупочную цену. Право на вычет задаётся вручную, автоматическая проверка налогового режима отсутствует. Это оценка прибыли до налогов на прибыль/УСН, не налоговая декларация. Налоговые настройки необходимо подтвердить с бухгалтером.

## Резервное копирование

Остановите приложение (Ctrl+C) и скопируйте `kp.sqlite3` в защищённое место. Для восстановления при остановленном приложении верните файл на прежнее место. База содержит коммерческую информацию, не добавляйте её в Git.
